# Rick Gautam Real Estate Website and Lead Portal

[Developer profile](https://github.com/LALITH-GAUTAM)

A real estate website and integration-ready lead-management portal for Rick Gautam, Associate Broker / REALTOR® with Century 21 Coastal Realty Ltd.

## Project scope

Public website routes and a local-development CRM, with boundaries for future listing-provider and database integrations.

## Technology

React, TypeScript, TanStack Start, Vite, and Tailwind CSS. The application repository includes a Supabase schema and production integration documentation.

## Current status

Development project. Live listings, server-backed lead management, and production administration require external integrations. This is not a fully integrated production CRM.

- Live listings require an authorized listing provider.
- Production lead capture and administration require server storage, authentication, CAPTCHA, notifications, and appropriate policies.
- Sample content and demonstration administration are restricted to development.

## Project record

This repository is the public project overview. Source code and integration details are maintained in the private `rick-gautam-real-estate` repository, previously named `rickgautam-elevate`. Its existing commit and pull request history is preserved.
